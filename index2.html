Comandos Git

Git Init

   
        git init - Inicializa repositorio e mantem um histórico

Git Status


            git status - podemos visualizar o funcionamento correto do repositorio

Git add


            git add - Para preparar os arquivos da pasta
            git add nome_pasta 
            git add.

Git comit


           git commit - Irá enviar uma mensagem de confirmação para GitHub
            git commit -m "mensagem que desejo"

Git Log


           git log - Irá exibir o historico de commits
           git log --oneline - Irá exibir o histórico de commits resumido

Git Branch


           git branch - Irá exibir as branches exixtentes
           git branch nome_da_branch - Irá criar uma nova branch
           git checkout nome_da_brench -m Irá alternar para a nome_da_brench especificada
           git branch -M main - Irá renomear a branch atual para main

Git remote


           git remote - Irá exibir os remotos configurados
           git remote add origin url - Irá adicionar um novo remote
           git push origin main - Irá enviar alterações para o remote
           git remote add origin link_repositorio
           git remote -v  - Irá mostrar a URL configurada do origin

Git Push


           git push - origin main - Irá enviar alterações para o remotegit 
           git push -u origin main -Irá enviar alterações para o remote e definir a branch atual como upstream
           git push origin main - ira enviar alterações
